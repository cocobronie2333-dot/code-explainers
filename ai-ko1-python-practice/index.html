练习：连续子数组计数

第一行有整数 n k，之后有 n 个整数，可正、可零、可负。统计有多少个非空连续子数组的和恰好为 k。输出一行整数。练习设定 0 ≤ n ≤ 200000。

输入
5 2
1 1 1 -1 2
输出
5

先写关系式。到当前位置的前缀和是 s，某个此前前缀和是 t，中间连续区间的和是 s-t。当 t=s-k，此前出现过多少次这个值，就有多少个以当前位置结尾的答案。

先手推样例，再验证 n=0 输出 0、[0,0,0], k=0 输出 6、[-1,1], k=0 输出 1。

展开参考实现和复杂度 
import sys

def count_subarrays(nums, k):
    seen = {0: 1}
    prefix = 0
    answer = 0
    for x in nums:
        prefix += x
        answer += seen.get(prefix - k, 0)
        seen[prefix] = seen.get(prefix, 0) + 1
    return answer

def main():
    data = iter(map(int, sys.stdin.buffer.read().split()))
    n, k = next(data), next(data)
    nums = (next(data) for _ in range(n))
    print(count_subarrays(nums, k))

if __name__ == "__main__":
    main()

seen = {0: 1} 计入数组起点之前的空前缀。先查询再记录当前前缀，避免在 k=0 时把长度 0 的区间也算进去。字典查找按均摊常数估算，时间 O(n)，额外空间 O(n)。

迁移到通用题

  • 事件或指令模拟：按题面顺序执行，维护状态与下标。
  • 多条件排序：例如 sorted(items, key=lambda x: (-x[1], x[0])) 表示第二项降序、第一项升序。
  • 区间频繁求和：设 prefix[0]=0，半开区间 [l,r) 的和为 prefix[r]-prefix[l]。
  • 网格最短步数：若每一步代价相同，用 deque 做 BFS，入队时标记已访问。
