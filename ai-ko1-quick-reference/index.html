知识点写题时怎么用用什么检查
NumPy* 逐元素，@ 矩阵乘。最后一轴归约用 axis=-1，要广播回原数组时加 keepdims=True。拿 2×3 矩阵检查每步 shape。
Softmax同行先减最大值，取指数，再除以指数和。相同 logits 概率相等，正常行概率和为 1。
Attentionscores = Q @ K.T / sqrt(dk) → 遮罩 → 按 key 轴 Softmax → weights @ V。分数 (Tq,Tk)，输出 (Tq,Dv)。因果自注意力第一行输出第一个 V。
遮罩Softmax 前把屏蔽的分数设为 -np.inf。等长因果遮罩允许 j ≤ i。核对 True 的含义。整行屏蔽按题面处理。
采样温度缩放 → 按题目次序筛选候选 → 概率归一化 → 抽原 token ID。Top-p 包含首个达到阈值的那一项。核对同分规则、截断后概率和、seed 位置。
训练与推理训练输入/标签错一个位置，前向求 loss、反向求梯度、更新参数。推理取最后位置 logits 选 token，再按停止条件循环。核对 padding 是否计入 loss、EOS 是否写入输出、步数上限。
通用题状态模拟、字典计数、排序键、前缀和，先写出哪一步更新什么。核对 n=1、重复、负数、并列、下标、I/O 格式。
