从矩阵到下一个 token

做完这一课，你应能闭卷写出逐行 Softmax、单头因果 Attention 和 Top-p，并用小矩阵验证每一步。

1. 先写 shape

表达式输入与输出含义
A @ B(m, d) × (d, n) → (m, n)矩阵乘法
x.sum(axis=-1, keepdims=True)(m, n) → (m, 1)每行一个和，保留维度以便广播
x[:, None] - y[None, :](m, 1) 和 (1, n) → (m, n)两组数的两两差

广播从右往左对齐，每个轴的长度相等或其中之一为 1。用 axis 聚合，就是沿指定轴合并元素。NumPy 官方快速入门

自测：x.shape = (2, 3)，x.sum(axis=0) 的形状是什么？

(3,)。第 0 轴有两行，聚合后每列保留一个结果。逐行求和用 axis=1。

2. 逐行 Softmax 与因果 Attention

每个 query 与所有 key 打分，每行在可见 key 上归一化，再按该行权重加权求和 value。令 q:(m,d)、k:(n,d)、v:(n,dv)，则分数为 (m,n)，输出为 (m,dv)。除以 sqrt(d) 抑制点积尺度随维度增大。Transformer 原论文 §3.2

下面的因果模板处理等长自注意力。约定 True 表示允许关注。Softmax 允许一行全部被遮住，并按本练习的约定返回全 0。

import numpy as np

def softmax(x):
    x = np.asarray(x, dtype=float)
    row_max = np.max(x, axis=-1, keepdims=True)
    row_max = np.where(np.isneginf(row_max), 0.0, row_max)
    exp = np.exp(x - row_max)
    total = exp.sum(axis=-1, keepdims=True)
    return np.divide(exp, total, out=np.zeros_like(exp), where=total > 0)

def attention(q, k, v, allowed=None):
    q, k, v = (np.asarray(a, dtype=float) for a in (q, k, v))
    scores = (q @ k.T) / np.sqrt(q.shape[-1])
    if allowed is not None:
        scores = np.where(allowed, scores, -np.inf)
    return softmax(scores) @ v

t = 2
allowed = np.arange(t)[:, None] >= np.arange(t)[None, :]
np.testing.assert_allclose(attention(np.eye(t), np.eye(t), [[2], [6]], allowed),
                           [[2], [4.6790462]], rtol=1e-7)
np.testing.assert_allclose(softmax([[1000, 1000], [-np.inf, -np.inf]]),
                           [[0.5, 0.5], [0.0, 0.0]])
自测：q 和 k 都是 2×2 全零矩阵，v = [[2], [6]]，因果 Attention 会输出什么？

[[2], [4]]。第一行权重为 [1, 0]，第二行权重为 [0.5, 0.5]。关闭遮罩后两行都输出 4。

进一层遇到 (B,H,T,D)，用 k.swapaxes(-1,-2) 交换最后两轴，分数是 (B,H,Tq,Tk)，仍沿最后一轴归一化。

3. 把候选概率变成 token ID

贪心取 argmax。温度取正值，先把 logits 除以温度，较小的温度让概率更集中。Top-k 保留分数最高的 k 项。Top-p 将概率降序排列，保留累计概率首次达到 p 的最短前缀，包含达到阈值的那一项。截断后重新归一化，抽样返回原 token ID。Nucleus Sampling 原论文 · NumPy 抽样接口

以下模板接收一维、非空、有限的 logits。并用 Top-k 和 Top-p 时，模板先在 Top-k 候选内归一化再执行 Top-p，考场按题面规定的次序实现。分数相同则保留原 ID 顺序。

def candidates(logits, temperature=1.0, k=None, p=1.0):
    z = np.asarray(logits, dtype=float)
    ids = np.argsort(-z, kind="stable")
    if k is not None:
        ids = ids[:k]  # 假设 1 <= k <= len(z)

    scaled = (z[ids] - z[ids[0]]) / temperature
    probs = softmax(scaled)
    if p < 1.0:  # 假设 0 < p <= 1
        end = np.searchsorted(np.cumsum(probs), p, side="left") + 1
        ids, probs = ids[:end], probs[:end]
    return ids, probs / probs.sum()

ids, probs = candidates(np.log([0.10, 0.50, 0.30, 0.10]), p=0.75)
np.testing.assert_array_equal(ids, [1, 2])
np.testing.assert_allclose(probs, [0.625, 0.375])
rng = np.random.default_rng(42)  # 在生成循环外初始化
token_id = int(rng.choice(ids, p=probs))
assert token_id in (1, 2)
自测：ID 0 到 3 的概率是 [0.125, 0.5, 0.25, 0.125]，Top-p = 0.75 时保留谁？

保留原 ID [1, 2]。累计到第二项恰好是 0.75，重新归一化后概率为 [2/3, 1/3]。

4. 训练和推理各走一遍

训练下一个 token 时，序列 [A,B,C,EOS] 可以拆成输入 [A,B,C] 与标签 [B,C,EOS]。对真实类别计算 -log(p_target)，对有效位置聚合，再反向传播并更新参数。

def cross_entropy(logits, labels):
    # logits: (n, vocab)，labels: (n,)，都对应有效位置
    logits = np.asarray(logits, dtype=float)
    shifted = logits - logits.max(axis=-1, keepdims=True)
    target = shifted[np.arange(len(labels)), labels]
    return (np.log(np.exp(shifted).sum(axis=-1)) - target).mean()

np.testing.assert_allclose(cross_entropy([[1000, 1000]], [1]), np.log(2))

题目给了 padding 忽略规则，就先筛选有效位置再计算，尤其留意平均值的分母。交叉熵定义

推理把 prompt 前向计算得到最后位置 logits，选 token，追加后继续预测，直到 EOS 或生成步数上限。Prefill 处理 prompt。Decode 逐步生成，可复用历史 K、V。模拟题先把剩余步数、已生成 token 和请求的终止条件写清楚。

以下练习约定返回新生成的 token，包含 EOS。next_logits 接收完整前缀，返回下一步的一维 logits，choose 返回选出的 token ID。

def generate(prompt, next_logits, choose, eos, max_new_tokens):
    prefix = list(prompt)
    generated = []
    for _ in range(max_new_tokens):
        token = int(choose(next_logits(prefix)))
        generated.append(token)
        if token == eos:
            break
        prefix.append(token)
    return generated

def toy_logits(prefix):
    return [0, 1] if len(prefix) == 1 else [1, 0]

assert generate([7], toy_logits, np.argmax, 0, 5) == [1, 0]
assert generate([7], toy_logits, np.argmax, 0, 1) == [1]
assert generate([7], toy_logits, np.argmax, 0, 0) == []
